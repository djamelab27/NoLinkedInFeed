# NoLinkedInFeed

A minimal Chrome extension to hide the LinkedIn home feed.

## Why

LinkedIn is useful, but the home feed can be distracting, I just don't like it.

This extension removes it entirely with a simple toggle.

## Features

- ON/OFF toggle
- Persistent setting
- Works on LinkedIn
- Lightweight and fast

## Installation

1. Download or clone this repository
2. Go to chrome://extensions
3. Enable Developer mode
4. Click "Load unpacked"
5. Select the folder
6. Open LinkedIn and reload

## Privacy

NoLinkedInFeed does not collect, store, or share any personal data.

It only saves a local preference (ON/OFF) using Chrome storage.
